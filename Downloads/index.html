Install

安装

  1. Download Elysia-1.0.0.dmg with the button above.
  2. Open the DMG and drag Elysia onto the Applications shortcut.
  3. Launch Elysia and allow it to control Music when macOS asks.
  1. 点击上方按钮下载 Elysia-1.0.0.dmg。
  2. 打开 DMG，把 Elysia 拖到 Applications 快捷方式上。
  3. 启动 Elysia，macOS 询问时允许它控制「音乐」。

The build is signed but not notarized, which needs a paid Apple Developer account. If macOS reports an unidentified developer, right-click Elysia in Applications and choose Open, or clear the quarantine flag:

安装包已签名，但未公证（公证需要付费的 Apple 开发者账号）。如果 macOS 提示「无法验证开发者」，可在「应用程序」中右键 Elysia 选择打开，或清除下载隔离标记： 

$ xattr -dr com.apple.quarantine /Applications/Elysia.app
